# Carrossel de Slides (infintos com manipulacao de DOM, com transition de slides finito e infinito)

Este projeto é uma maneira simples de como slides podem ser aplicados, futuramente eu meus projetos usarei os modelos com transition finito e infinito

## 🚀Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (DOM, eventos, criação dinâmica de elementos)

## 🎯Objetivos

* Praticar manipulação do DOM
* Aprender a criar elementos dinamicamente com JavaScript
* Trabalhar com eventos do teclado e do mouse
* Praticar a criacao de slides de imagens
* Simular funcionalidades usadas em aplicações reais
